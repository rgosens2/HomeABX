HomeABX
=======

HomeABX is a suite of programs for doing audio hardware and software [double-blind](http://en.wikipedia.org/wiki/Blind_experiment#Double-blind_trials) [ABX](http://en.wikipedia.org/wiki/ABX_test) tests. It can be  used for comparing all sorts of [hi-fi](http://en.wikipedia.org/wiki/hifi) components and for comparison of different [audio file formats](http://en.wikipedia.org/wiki/Audio_file_format).

HomeABX can be used to objectively determine audio [transparency](https://en.wikipedia.org/wiki/Transparency_(data_compression)).

HomeABX consists of [HardABX](http://hardabx.blogspot.nl/p/manual.html) and [SoftABX](http://softabx.blogspot.com/).
